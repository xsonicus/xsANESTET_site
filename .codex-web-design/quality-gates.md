# Website Quality Gates

## Plan

- [ ] Brief and audience are explicit.
- [ ] External source and asset licenses are reviewed.
- [ ] Real/generative asset plan exists.
- [ ] Motion and reduced-motion plan exists.
- [ ] Claims, testimonials and metrics have evidence or explicit placeholders.

## Implementation

- [ ] Brand, product, place, person or literal offer is visible in the first viewport.
- [ ] A hint of the next section remains visible on desktop and mobile.
- [ ] No nested cards, clipped text, incoherent overlaps or layout shifts.
- [ ] Keyboard, semantics, contrast and reduced motion pass.
- [ ] Primary media reveals the real subject or state.

## Release

- [ ] Playwright screenshots pass at desktop and mobile viewports.
- [ ] Console errors and failed requests are zero or explicitly accepted.
- [ ] Lighthouse targets: performance 90, accessibility 95, best practices 95, SEO 90.
- [ ] Core Web Vitals targets: LCP <= 2500ms, INP <= 200ms, CLS <= 0.1.
- [ ] 3D, when used, is nonblank, framed, interactive, moving and has a fallback.
