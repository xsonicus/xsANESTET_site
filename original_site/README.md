# QK Cosmetic / ANESTET source snapshot

Captured from the authorized MODX manager and the public site on 2026-08-28.

Contents:

- 704 frontend/media files under `assets/` (699 public downloads + 5 manager-recovered files).
- 14 MODX templates.
- 80 MODX chunks.
- 68 MODX snippets.
- 21 template variables.
- 20 MODX plugins.
- 50 resources, including the current miniShop2 product catalog.

The JSON exports are in `modx-export/`; downloaded-file provenance is in `asset-inventory.json`.

Intentionally excluded: `core/config`, database credentials, private keys, active session data, cache and logs. The snapshot is suitable for design reconstruction and migration work, but it is not a restorable database/server backup.
