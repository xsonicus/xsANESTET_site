# ANESTET 2026.08.28-v10

Первый публично версионируемый релиз нового магазина.

## Покупка без длинного скролла

- По умолчанию открывается каталог.
- Подробный подбор по трём этапам вынесен в отдельную тематическую вкладку.
- Одностраничная версия сохранена и доступна через верхний переключатель.

## Новинки Queen Key

- Hero автоматически перелистывает только два новых синих продукта каждые 4,6 секунды.
- Добавлены ручное переключение, заметная цена и нейтральная кнопка добавления в корзину.

## Корзина

- Корзина сохраняется между визитами.
- Работают изменение количества, удаление и очистка.
- Заказ формируется в WhatsApp с составом и итоговой суммой.

## Дизайн и качество

- Добавлена вторая крупная медленная диагональная брендовая строка.
- Номер, заголовок и подписи карточек этапов получили безопасные внутренние отступы.
- Автотест блокирует выпуск при касании текста к границам на 7 ширинах, в 2 темах и 3 представлениях.
- Все 23 packshot-изображения используют прозрачный фон.

## Инфраструктура

- Подключены Git, changelog, теги, GitHub Releases и CI.
- В репозитории сохранён безопасный снимок исходного MODX/miniShop2-сайта.
- Документирована целевая интеграция 1С, CDEK, склада, заказов, акций и админки.
- Секреты, конфиг базы, сессии, кэш и логи исключены из публичного репозитория.

- production build;
