# 2026.09.01-v13.2.0

Сводный production-релиз накопленных правок ANESTET: первый экран, две темы, VK-интеграция, защищённая админка и исторический граф проекта.

## Первый экран и графика

- Сохранён единственный утверждённый Prism-переход с интервалом 7 секунд и синхронным blur-переходом текста.
- GetLayers Opaline и облегчённый optical-halo взаимоисключающие: desktop с доступным WebGL показывает одну Opaline-сцену, mobile/reduced-motion/WebGL failure — один большой живой ореол вокруг всего товара.
- Удалён отдельный белый круг-пьедестал. Товар в мобильной сцене опущен ближе к оптическому центру и увеличен без столкновения с подписью и корзиной.
- CSS-тень включена во все фазы Prism и больше не возникает отдельным скачком после окончания перехода.
- Цена стала крупнее и контрастнее; длинные мобильные заголовки сохраняют нормальный шрифт и не режутся внутри слова.

## Бренды, About и footer

- Hero показывает `Anestet®` для профессиональных линеек и официальный Queen Key Cosmetic lockup без круглой монограммы для Queen Key.
- Большая дублирующая бренд-сцена footer удалена. Сохранена только компактная переливающаяся строка ANESTET / Clinical Care / Queen Key и служебная навигация.
- Обе темы используют одну компактную About-композицию: исходный портрет без генеративной дорисовки, увеличенная подпись «Александр Ермолаев / Основатель компании» и отсутствие пустого нижнего этажа.
- Высота доказательного блока и брендовых элементов уменьшена; мобильная и desktop-композиции проходят одинаковый layout gate.

## Один магазин и VK

- Удалены одностраничная версия и белая сравнительная полоса. Оставлен один полный магазин с двумя утверждёнными темами и отдельным внутренним guide-маршрутом.
- Блок «Новости, видео, формулы» принимает только реальные VK video/photo публикации и показывает их движущейся лентой квадратных обложек с заголовками и краткими описаниями. Telegram-карточки удалены; Telegram и Taplink остаются отдельными ссылками в верхней панели.
- В защищённой админке доступны VK domain/API version/token, проверка соединения, постраничная синхронизация всей доступной ленты, скрытие публикации и необязательная привязка к товару.
- VK-токен хранится только server-side в AES-256-GCM encrypted store; клиент получает маскированный статус. Без официального токена система остаётся fail-closed и ничего не выдумывает.

- Project Logic Graph ретроспективно хранит требования, первые реализации, correction-of-correction, текущие решения, связи и доказательства v10→v13.2.0.
