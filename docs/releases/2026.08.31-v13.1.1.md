# 2026.08.31-v13.1.1

Production-релиз полного магазина ANESTET с двумя утверждёнными темами и защищённой админкой.

## Что завершено

- GetLayers Opaline и Shoal загружаются как самостоятельные локальные HTML-сцены; iframe больше не может рекурсивно подставить страницу магазина. Opaline остаётся под товаром, а её световой слой растворяется без вертикальной границы.
- Footer тёмной темы получил явные светлые цвета для ANESTET, Queen Key, служебных ссылок и релиза; указатель мыши продолжает управлять локальным светом.
- Все 23 аутентичных packshot-мастера переведены в lossless WebP с побайтно идентичным декодированным RGBA. Для каталога добавлены отдельные 600×600 lossless-копии; растровых теней нет, тень создаёт CSS.
- Единственный продуктовый переход — Prism; упаковка сохраняет позицию, а подпись уходит воздушным blur и раскрывается заново.
- Сохранены новый-first сортировка, скидка Queen Key, избранное/корзина в браузере, обратный звонок, увеличенный Александр, компактный about-блок и четыре служебные ссылки ниже него.
- `/admin/` использует отдельную авторизацию, ревизии каталога, скидки/публикацию и маскированные fail-closed статусы будущих 1С/CDEK-коннекторов. Секреты не передаются в браузер.

## Проверка

- `npm run build && npm run qa:layout` — PASS, 11 экранов × 2 темы × 3 представления.
- `npm run qa:admin` — PASS: auth/origin/CSRF, 23 товара, create/update/soft-hide и revision, скидки, redaction, 1С/CDEK fail-closed.
- `npx tsc --noEmit`, `git diff --check`, `npm audit --omit=dev` — PASS.
- Packshot RGBA: `23/23 PASS` после lossless WebP-декодирования.
- Codex local Browser: обе темы, desktop/mobile, отдельный canvas сцены, footer и admin без рекурсивного iframe.

## Откат

Статика, Order API и Admin API публикуются в отдельных неизменяемых каталогах. Переключение выполняется атомарными симлинками; предыдущий production-релиз `20260828-v11.1.3` сохраняется для немедленного отката.
