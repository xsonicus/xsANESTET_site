# Статус интеграций

| Контур | Статус | Источник / следующий шаг |
| --- | --- | --- |
| Каталог и цены | Работает в релизе | Серверный Order API повторно проверяет ID, название и цену перед сохранением. |
| Заказы | Работает в релизе | `POST /api/orders`, закрытое хранилище VPS, номер `AN-…`. |
| Поддержка | Работает | `support@anestet.com` и официальные публичные каналы исходного магазина. |
| WhatsApp оператора | Резервный канал | Ссылка формируется из подтверждённой корзины; для WhatsApp Business API нужен номер и токен. |
| CDEK | Интерфейс готов, API закрыт | Компонент `msCDEK2` обнаружен в снимке MODX, но действующих credentials в снимке нет. |
| ЮKassa | Адаптер обнаружен, оплата закрыта | Компонент `msPyooKassa` есть в снимке; merchant credentials не экспортированы. |
| 1С / Bitrix | Контракт готов, не подключено | Нужны endpoint, тестовый доступ, карта SKU и правила резервирования. |
| Остатки | Fail-closed | Показывается нейтральный статус, пока master-система не отдаёт актуальный остаток. |
| VK Feed | Адаптер и модерация готовы, токен задаётся в админке | `wall.get` импортирует новости с фотографиями и видео; администратор привязывает материал к товару и публикует. Токен шифруется AES-256-GCM в серверном хранилище и не возвращается в браузер. До его сохранения исходящих запросов нет. |

Секреты устанавливаются только на VPS через закрытые env-файлы. Значения не печатаются в CI/CD, не попадают в статический JavaScript и не коммитятся.
