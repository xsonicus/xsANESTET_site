# История релизов ANESTET

Эта история разделяет фактически сохранённые VPS-артефакты и полноценную Git-историю. Исходные коммиты до подключения GitHub не реконструируются задним числом.

## Сохранённые VPS-релизы

На сервере сохранены статические сборки `20260828-v1` — `20260828-v9`. Активный релиз до внедрения GitHub: `20260828-v9`.

- `v1–v7` — итерации трёх визуальных направлений, адаптива, каталога, прозрачных packshot-изображений и брендовой айдентики.
- `v8` — две финальные темы, оригинальные логотипы, продуктовые тени, брендовые диагональные строки и переработанный подвал.
- `v9` — второй крупный медленный брендовый слой в hero без ухудшения CLS; сохранённая одностраничная версия до коммерческого UX-релиза.

## GitHub-релизы

### 2026.08.28-v10

- Каталог открывается первым, без обязательного длинного чтения.
- Подбор по трём этапам вынесен в отдельную тематическую вкладку.
- На первом экране автоматически меняются только новые синие продукты Queen Key каждые 4,6 секунды.
- Цена выделена сильнее, товар можно сразу добавить в корзину.
- Корзина сохраняется между визитами, поддерживает количество и формирует заказ в WhatsApp.
- Для карточек этапов введена безопасная внутренняя зона; автоматический тест проверяет касания текста на 7 ширинах, в 2 темах и 2 режимах.
- В подвал добавлен номер модификации со ссылкой на GitHub Releases.
- В репозиторий включён безопасный снимок исходной MODX/miniShop2-системы и конфигурация нового nginx-развёртывания.
- Добавлен верхний переключатель `Было / Одностраничный / Полный сайт` и документирована единая серверная архитектура для 1С, CDEK, остатков, заказов, акций и админки.

Следующие изменения оформляются отдельным коммитом, записью в `CHANGELOG.codex.md`, Git-тегом и GitHub Release.

### 2026.08.28-v10.1

- Исправлены ARIA-связь динамического тематического режима и доступное имя счётчика корзины.
- Lighthouse Accessibility восстановлен до 100 без визуального изменения дизайна.

### 2026.08.28-v10.2

- Белая подложка Chromatic Serum теперь геометрически центрируется относительно продуктовой колонки на высоких экранах.
- Для портретных desktop/tablet-пропорций увеличен интервал между вертикальной служебной подписью и заголовком.
- Высокий экран 1431 × 1728 добавлен в обязательную responsive QA-матрицу.

### 2026.08.28-v11

- Восстановлена типографика исходного магазина: Open Sans для интерфейса и Unbounded для заголовков.
- Герой показывает только новинки Queen Key, выравнивает упаковки по визуальному масштабу и меняет их мягкой масочной анимацией.
- Добавлены исходный текст о бренде, блок принципов и брендовая фотография; ссылки ведут на действующие разделы оригинального магазина.
- Добавлены официальные VK, Telegram и Taplink, отдельная поддержка по e-mail и динамическая лента социальных материалов.
- Корзина получила выбор доставки, адрес, комментарий, серверную проверку цен и реальный номер заказа.
- Order API сохраняет заказы на VPS; административное чтение закрыто отдельным токеном.
- Внешние 1С/Bitrix, CDEK, ЮKassa, VK Feed и WhatsApp API работают только после защищённой установки действующих реквизитов.

### 2026.08.28-v11.0.1

- Оригинальные Open Sans и Unbounded загружаются до первого рендера hero, чтобы исключить смещение продуктовой сцены при подмене системного шрифта.
- Функциональность v11 и интервал автоперелистывания новинок сохранены без изменений.

### 2026.08.28-v11.1.2

- Верхний переключатель снова сравнивает ровно три версии: `Старый сайт / Одностраничный / Полный сайт`.
- `Старый сайт` открывает оригинальный `qkcosmetic.ru` в новой вкладке; остальные переходы нового магазина остаются внутренними.

### 2026.08.28-v11.1.3

- Мобильная шапка переразложена в устойчивую сетку: логотип остаётся слева, а VK, Telegram, поддержка и корзина выровнены в компактную группу.
- Корзина стала круглой 44×44 px кнопкой со счётчиком-бейджем и больше не выходит за правую границу экрана.
- Layout gate теперь отдельно проверяет каждый элемент шапки на выход за viewport, вертикальное смещение и пересечение с логотипом, включая ширину 644 px из клиентского кадра.

### 2026.08.28-v11.1.1

- Заголовок обеих тем и всех представлений обновлён до «Точная формула, / спокойная кожа, / всегда и везде».
- Матрица безопасных переносов повторно проверена на всех контрольных ширинах.

### 2026.08.28-v11.1.0

- Hero перелистывает все восемь актуальных новинок каждые 4,6 секунды и позволяет добавить каждую из них в корзину прямо с первого экрана.
- Все 23 packshot-изображения нормализованы в WebP с настоящим alpha-каналом, безопасным масштабом и единым визуальным центром.
- Исправлены пересечения упаковок с плашками и кнопками; обязательная матрица расширена до 10 экранов, 2 тем и 3 представлений.
- Старый магазин больше не открывается из нового интерфейса: партнёры, доставка и оплата, сертификаты и контакты перенесены во внутренние вкладки.
- В верхнюю панель добавлены VK, Telegram и рабочая внутренняя кнопка поддержки; социальные карточки получили оригинальные иконки площадок.
- Заголовок закреплён в трёх строках: «Точная формула, / спокойная кожа, / всегда»; улучшена резкость портрета Александра без изменения личности.
- Корзина проверена от hero до оформления: количество, пять способов доставки, получатель, итог, серверный заказ и WhatsApp-fallback.
- Исправлены доступное имя поддержки, контраст активной вкладки и приоритет загрузки крупного брендового трафарета.
