# История релизов ANESTET

Эта история разделяет фактически сохранённые VPS-артефакты и полноценную Git-историю. Исходные коммиты до подключения GitHub не реконструируются задним числом.

## Сохранённые VPS-релизы

На сервере сохранены статические сборки `20260828-v1` — `20260828-v9`. Активный релиз до внедрения GitHub: `20260828-v9`.

- `v1–v7` — итерации трёх визуальных направлений, адаптива, каталога, прозрачных packshot-изображений и брендовой айдентики.
- `v8` — две финальные темы, оригинальные логотипы, продуктовые тени, брендовые диагональные строки и переработанный подвал.
- `v9` — второй крупный медленный брендовый слой в hero без ухудшения CLS; сохранённая одностраничная версия до коммерческого UX-релиза.

## GitHub-релизы

### 2026.08.28-v10

- Каталог открывается первым, без обязательного длинного чтения.
- Подбор по трём этапам вынесен в отдельную тематическую вкладку.
- На первом экране автоматически меняются только новые синие продукты Queen Key каждые 4,6 секунды.
- Цена выделена сильнее, товар можно сразу добавить в корзину.
- Корзина сохраняется между визитами, поддерживает количество и формирует заказ в WhatsApp.
- Для карточек этапов введена безопасная внутренняя зона; автоматический тест проверяет касания текста на 7 ширинах, в 2 темах и 2 режимах.
- В подвал добавлен номер модификации со ссылкой на GitHub Releases.
- В репозиторий включён безопасный снимок исходной MODX/miniShop2-системы и конфигурация нового nginx-развёртывания.
- Добавлен верхний переключатель `Было / Одностраничный / Полный сайт` и документирована единая серверная архитектура для 1С, CDEK, остатков, заказов, акций и админки.

Следующие изменения оформляются отдельным коммитом, записью в `CHANGELOG.codex.md`, Git-тегом и GitHub Release.

### 2026.08.28-v10.1

- Lighthouse Accessibility восстановлен до 100 без визуального изменения дизайна.

### 2026.08.28-v10.2

- Для портретных desktop/tablet-пропорций увеличен интервал между вертикальной служебной подписью и заголовком.
- Высокий экран 1431 × 1728 добавлен в обязательную responsive QA-матрицу.

### 2026.08.28-v11

- Восстановлена типографика исходного магазина: Open Sans для интерфейса и Unbounded для заголовков.
- Герой показывает только новинки Queen Key, выравнивает упаковки по визуальному масштабу и меняет их мягкой масочной анимацией.
- Добавлены исходный текст о бренде, блок принципов и брендовая фотография; ссылки ведут на действующие разделы оригинального магазина.
- Добавлены официальные VK, Telegram и Taplink, отдельная поддержка по e-mail и динамическая лента социальных материалов.
- Корзина получила выбор доставки, адрес, комментарий, серверную проверку цен и реальный номер заказа.
- Order API сохраняет заказы на VPS; административное чтение закрыто отдельным токеном.
- Внешние 1С/Bitrix, CDEK, ЮKassa, VK Feed и WhatsApp API работают только после защищённой установки действующих реквизитов.

### 2026.08.28-v11.1.0

- Hero перелистывает все восемь актуальных новинок каждые 4,6 секунды и позволяет добавить каждую из них в корзину прямо с первого экрана.
- Все 23 packshot-изображения нормализованы в WebP с настоящим alpha-каналом, безопасным масштабом и единым визуальным центром.

- В верхнюю панель добавлены VK, Telegram и рабочая внутренняя кнопка поддержки; социальные карточки получили оригинальные иконки площадок.
- Заголовок закреплён в трёх строках: «Точная формула, / спокойная кожа, / всегда»; улучшена резкость портрета Александра без изменения личности.

### 2026.08.31-v12.0.0

- Добавлены три самостоятельные визуальные версии магазина: Clinical Luxury, Beauty Editorial и Future Beauty, с переключателем в верхней части сайта.
- В hero встроены локально материализованные сцены GetLayers Shoal и Opaline; на мобильных устройствах и при reduced motion работают статические облегчённые версии.
- Все 23 товара, подтверждённые цены, корзина, Order API, варианты доставки и WhatsApp-fallback сохранены общими для трёх дизайнов.
- Наличие показывается компактным знаком `?` с пояснением, что остаток уточняет менеджер до подключения 1С.
- Обязательная матрица расширена до 11 экранов, 3 дизайнов и 3 представлений; локальная визуальная приёмка выполняется в Codex Browser.
- В nginx добавлено gzip-сжатие: локальный Lighthouse с эквивалентной production-компрессией — 99 / 100 / 100 / 100, LCP 1,8 с, CLS 0.

### 2026.08.31-v12.1.0

- В Future Beauty единая Opaline-аура перенесена непосредственно за продукт; прежний второй круг заменён мягкой световой опорой под упаковкой.
- Блок «Сразу купить или подобрать» собран в две фиксированные строки, а кнопки маршрута стали ниже и плотнее без потери 44 px touch-target.
- Портрет Александра уменьшен и получил отдельную оптическую сцену с редкими искрами; нижняя часть тёмной темы и footer связаны тем же световым мотивом.
- Декоративное движение ограничено transform/opacity, запускается только у видимых секций и полностью учитывает reduced motion.
- Packshot-аудит проверяет ровность прозрачного alpha-контура отдельно от этикетки: русские надписи, логотипы, цвет и форма упаковок не реконструируются.

### 2026.08.31-v13.0.0

- Оставлен один устойчивый hero-переход «Призма»: упаковка не смещается и не меняет масштаб, меняются только световые срезы и прозрачность. Подпись старого товара уходит с воздушным blur, новая раскрывается последовательно.
- Портрет Александра заново обрезан по исходной прозрачности, увеличен и помещён в компактную живую сцену с оптическими орбитами; пустая высокая капсула удалена.
- На витрине появились избранное с сохранением в браузере, акция Queen Key `890 ₽ / 1 190 ₽`, форма обратного звонка и официальный QK Cosmetic lockup.
- Каталог стал общим для витрины, Order API и защищённой `/admin/`: товары, публикация, обычная/старая цена и статусы редактируются серверно с журналом и контролем ревизии.
- В админке добавлен fail-closed раздел интеграций 1С, СДЭК и универсального connector API. Секреты остаются только на сервере; до появления официальных контрактов реальные внешние запросы отключены.
- Все 23 packshot-изображения переведены на versioned прозрачные PNG; внутренние RGB-пиксели, русские надписи, логотипы и этикетки не перерисовываются.
- Утверждены две темы: тёмно-синяя Future Beauty по умолчанию и светлая Clinical Luxury. Промежуточная Beauty Editorial удалена из интерфейса.
- Release gate: production build и `11 экранов × 2 темы × 3 представления` проходят без overflow, clipping и пересечений. Выпуск остаётся локальным кандидатом и на VPS не развёрнут.

### 2026.08.31-v13.1.0

- Все 23 товара используют проверенные `*-alpha-restored-v2.png`: один связный foreground, прозрачные края без растровой тени, сохранённые исходные этикетки и русский текст; тень создаётся только CSS.
- Новинки сортируются первыми внутри выбранного раздела. Мобильный hero получил сокращённую подпись и отдельный лёгкий оптический акцент.
- В footer восстановлена правильная иерархия Queen Key: отдельная монограмма внутри орбиты, официальный QK Cosmetic ниже и читаемая подпись на тёмном фоне.
- Исправлена ложная hydration-ошибка Comet/Bybit: расширение добавляло `data-bybit-*` в корневой HTML до React; production-консоль после корректировки чистая.
- `/admin` завершена и проверена: защищённый вход, создание/редактирование/soft-hide 23 товаров, optimistic revision, скидки, скрытие секретов и fail-closed 1С/СДЭК. VPS deployment не выполнялся.

### 2026.08.31-v13.1.1

- Админка, общий каталог, Order API и статический сайт подготовлены как три независимых неизменяемых VPS-релиза с атомарным переключением и сохранением предыдущей версии для отката.

### 2026.09.01-v13.1.2
